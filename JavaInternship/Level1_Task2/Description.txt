Description:

The Palindrome Checker is a Java console-based application developed as part of the Level 1 internship tasks. The program accepts a word or phrase from the user and determines whether it is a palindrome by ignoring spaces, punctuation, and case sensitivity. It utilizes string manipulation techniques and implements the efficient two-pointer approach to compare characters from both ends of the string. This task demonstrates strong understanding of loops, conditional statements, and optimized logical problem-solving in Java.
